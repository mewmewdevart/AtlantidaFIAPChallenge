# O Atlante: regras e vocabulário

O idioma "Atlantida" do site é inventado. Ele mistura línguas e dialetos da América Latina para formar um dialeto novo, o **Atlante**, que não pertence a nenhum povo em particular. Este arquivo diz **como ele funciona** e **de onde vem cada palavra**, para o time continuar traduzindo sem se contradizer.

> **Importante:** é uma criação artística. As raízes foram escolhidas de memória, a escrita varia entre os dialetos de cada língua e algumas palavras foram inventadas por analogia (marcadas com ★). Antes de publicar fora do desafio, vale conferir com dicionários ou falantes.

Para checar se sobrou português nas traduções: `node assets/js/tests/verificar-atlante.js`.

## 1. Ideia geral

- **Gramática emprestada do quéchua**, simplificada. É o "esqueleto" de todas as frases.
- **Vocabulário por ofício.** Cada habitante fala com palavras de uma língua diferente, o que dá a impressão de uma cidade feita de muitos povos:

| Quem / ofício | Língua das palavras | Exemplos |
|---|---|---|
| Kora (fogo, calor, pressão) | mapudungun | `kütral` fogo, `newen` força |
| Mestra Zilda (memória, palavras) | náuatle | `tlahtol` palavra, `cuicatl` canto, `amoxcalli` biblioteca |
| Tito (fundo, mergulho, sucata) | quéchua e aimará | `ukhu` fundo, `qucha` mar, `uma` água |
| Yara (algas, jardins) | quéchua | `cochayuyo` alga, `wayra` ar, `mallki` broto |
| Beto (paredes, solda) | náuatle | `tepantli` parede, `tepoz` ferro |
| Sueli (rádio, canal) | guarani | `ñe'ẽ` voz, palavra |
| Gramática, lugares e o resto | quéchua | `wasi` casa, `llaqta` cidade |

## 2. Regras de gramática (as que o texto do site usa)

| Regra | Como é | Exemplo |
|---|---|---|
| Ordem | objeto antes do verbo; quem modifica vem antes | `cablekunata pallay` = recolher cabos |
| Plural | `-kuna` | `cúpulakuna` = as cúpulas |
| Em / no | `-pi` | `Inti Sonqopi` = no Coração do Sol |
| De (posse) | `-p` ou `-pa` | `Betop mesan` = a mesa do Beto |
| Objeto | `-ta` | `yakuta` = a água (como objeto) |
| Com | `-wan` | `llank'aqmasinkunawan` = com os colegas |
| De (origem) | `-manta` | `ukhumanta` = do fundo |
| Para | `-paq` | `upyanapaq` = para beber |
| Ordem de fazer | só o radical em `-y` | `willay` = conte, `wichqay` = feche |
| Passado | `-rqa` (eles: `-rqanku`) | `uraykurqanku` = desceram |
| Presente | `-n` ou `-shan` (acontecendo agora) | `llank'ashan` = está trabalhando |
| Não | `mana` antes do verbo | `mana k'anchaq` = que não acende |
| Pergunta | `pitaq` quem, `imataq` o quê, `imaynatam` como, `haykapitaq` quando | |
| Ênfase | `-m` / `-qa` no fim da palavra | `Titum willarqa` = foi o Tito quem avisou |

Números seguem o quéchua: `kimsa` 3, `suqta` 6, `iskay chunka hukniyuq` 21.

## 3. Nomes de lugares, pessoas e coisas do site

| Português | Atlante | Como se formou |
|---|---|---|
| Atlântida (a cidade, para quem vive nela) | **Ñandeyaku** | `ñande` guarani "nosso" + `yaku` quéchua "água" |
| Coração do Sol | **Inti Sonqo** | `inti` sol + `sonqo` coração (quéchua) |
| Jardins de Alga | **Cochayuyo Chakra** | alga + horta (quéchua) |
| Casa das Vozes | **Ñe'ẽ Wasi** | `ñe'ẽ` guarani "voz" + `wasi` casa |
| Estaleiro | **Tepan Wasi** | `tepan` náuatle "parede" + `wasi` casa |
| Terraços d'Água | **Yaku Pata** | água + terraço (quéchua) |
| Anel de Fora | **Hawa Muyu** | `hawa` fora + `muyu` círculo (quéchua) |
| Praça | **Kancha** | pátio (quéchua) |
| Biblioteca | **Amoxcalli** | náuatle: casa dos livros |
| Chasqui | **Chaski** | mensageiro (quéchua) |
| Lei da casa | **Wasi kamachiy** | casa + ordem (quéchua) |
| Mapa da cidade | **Llaqta mapu** | cidade + mapa |
| O pulso da cidade | **Llaqtayolotl** | `llaqta` cidade + `yolotl` náuatle "coração" |
| Nossa história | **Ñuqanchik willakuy** | "nós (todos)" + história |

Funções dos habitantes: `Kamayuq` = encarregado de, `Tarpuq` = quem planta, `Mashkaq` = quem procura, `Llank'aq` = quem trabalha, `Chaski` = mensageiro, `Waqaychaq` = quem guarda, `Amawta` = mestra, sábia.

## 5. Como traduzir um texto novo

1. Escreva a frase em português **curta e direta** (traduz melhor).
2. Troque as palavras pelas da tabela (use a língua do ofício de quem fala).
3. Monte a frase com a gramática da seção 2: objeto antes do verbo, sufixos no fim da palavra.
4. Se faltar uma palavra, **invente por analogia** (junte duas raízes) e acrescente a linha na tabela com ★.
5. Rode `node docs/verificar-atlante.js` (O Mundo e Habitantes) e `node docs/verificar-idiomas.js` (menu, Mural, Contato, rodapé) para ver se algo ficou sem tradução.
